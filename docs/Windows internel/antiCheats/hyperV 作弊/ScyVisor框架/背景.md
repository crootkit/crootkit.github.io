# 作者描述

如果你正在做作弊，厌倦了不断被反作弊软件检测并关闭你的项目，ScyVisor 就是为解决这个问题而设计的。它是一个基于虚拟机管理程序的框架，允许你在低层次**绕过 EAC 和 BattleEye**，完全控制进程内存、内核交互和系统功能——同时保持完全隐藏。  
  
有了 ScyVisor， _你不用担心_被发现的风险，也不用频繁更新旁通系统。相反，你可以完全专注于开发用户模式功能（ESP、自动瞄准器等），而框架则负责反作弊部分。

- Read & write game memory at both the physical and virtual level.  
    在物理和虚拟层面都能读写游戏内存。
- Fully hide kernel and usermode processes from anti-cheat detection.  
    完全隐藏内核和用户模式进程，防止反作弊检测。
- Hook and disable anti-cheat functions to prevent them from interfering with your code.  
    挂钩并禁用反作弊功能，防止它们干扰你的代码。
- Debug anti-cheat kernel modules without triggering protection mechanisms.  
    调试无触发保护机制的反作弊内核模块。
- Completely hide internal modules within other processes.  
    完全隐藏内部模块在其他进程中。
- Mask overlay applications to prevent them from being flagged.  
    使用掩码覆盖应用以防止它们被标记。
- Bypass integrity checks and signature verification to ensure persistence.  
    绕过完整性检查和签名验证，确保持久性。
