
# 为什么需要

如果说有什么命令能让 Active Directory 管理员胆战心惊，那 `lsadump::dcsync` 。这堪称凭证窃取的“皇冠上的明珠”，它从根本上改变了我们对 Active Directory 安全性的认知。多年来，提取域凭证需要对域控制器拥有物理或管理权限，无论是转储 `ntds.dit` 文件还是抓取 LSASS 内存。这两种方法都噪音巨大、侵入性强，而且越来越容易被现代 EDR 解决方案检测到。

DCSync 彻底改变了一切。它允许我们使用域控制器自身的复制协议，从网络中请求任何用户的密码哈希值。我们无需触碰磁盘，无需触碰内存，也无需登录域控制器本身。我们只需使用域控制器之间通用的语言礼貌地提出请求即可。

# 工作流程

根据我的经验，DCSync 是连接“域管理员”和“域所有者”的最佳桥梁。它利用了 **MS-DRSR** （目录复制服务远程协议）——域控制器之间同步目录数据库的同一机制。通过告知域控制器“您好，我也是域控制器，请将管理员帐户的最新更新发送给我”，我们就能收到 NTLM 哈希值、Kerberos AES 密钥和完整的密码历史记录，而不会触发传统的凭据转储警报。
